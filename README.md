# **TOM: Task Organizer Manager**
TOM is a a web system focused on task management and organization, developed and designed to help students manage their coursework more effectively. It aims to help students efficiently manage their academic workload and improve their performance.

In Partial Requirements of **CIT-210** & **CC 205**
